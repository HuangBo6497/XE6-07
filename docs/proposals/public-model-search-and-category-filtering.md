# 提案：关键词搜索与分类筛选公共模型

## 动机 / 用户故事

用户需要在公共模型库中输入关键词，并按一级分类筛选，从已公开模型中快速找到目标。本提案只负责缩小公共列表结果，不包含模型详情、下载、收藏或 Fork。

## 目标用户

- 浏览公共模型库并寻找模型的普通用户
- 维护统一分类和公开状态的运营或管理人员

## 现有做法及不足

公共模型列表缺少按标题、标签和一级分类缩小结果的能力，用户需要手动浏览大量模型，且无法稳定区分无结果与加载失败。

## 本期范围

本期做：

- 按模型标题和标签进行简单、可预测的包含匹配。
- 忽略关键词首尾空格，英文字母不区分大小写。
- 空关键词恢复全部公开模型。
- 提供“全部”和系统统一的一级分类；默认选择“全部”，每次只选择一个分类。
- 关键词和分类同时生效，结果必须同时满足两个条件。
- 结果继续使用公共模型卡片，并按公开时间倒序排列。
- 页面展示当前条件、结果数量和“清除全部条件”操作。
- 更换关键词或分类后从第一页重新加载；“加载更多”只加载当前条件下的结果。
- 区分无结果和加载失败，并提供重试入口。
- 搜索始终只返回已审核通过且未下架的模型。

本期明确不做：

- 不做语义搜索、LLM 搜索、拼写纠正、同义词、建议、自动补全、历史或热门关键词。
- 不按作者、描述或文件内容搜索。
- 不做多级或多选分类。
- 不做材料、难度、授权方式筛选和复杂排序。
- 不做模型详情、收藏、下载、举报和 Fork。

## 关键决策与依据

### 备选方案

1. 先实现语义搜索、推荐和复杂筛选。
   - 优点：搜索表达能力更强。
   - 缺点：行为难以预测，范围和验证成本较大。
2. 使用标题 / 标签的包含匹配，加一个统一的单选一级分类。
   - 优点：规则简单、结果可解释，能覆盖公共模型库的首要查找需求。
   - 缺点：不处理语义相近、拼写错误或复杂排序。

### 本期选择

选择方案 2。

原因：本期目标是快速缩小公共列表，而不是建立完整搜索引擎；简单匹配与统一分类更容易验证，也能保证公开状态安全边界。

## 基本概念与信息结构

### 搜索条件

- `keyword`: 标题或标签的包含匹配关键词
- `category`: 全部或一个系统提供的一级分类
- `page`: 当前条件下的分页位置

### 公开模型结果

只包含已审核通过且未下架的模型，并按公开时间倒序排列。分类值由系统统一提供，发布者不能创建语义相同但写法不同的分类。

## 原型 / 演示

公共模型列表顶部提供关键词输入框、一级分类下拉框、结果数量和清除全部条件操作。列表底部提供加载更多；无结果显示调整条件提示，加载失败显示错误和重试入口。

## 验收标准

### 例子 1：标题与标签关键词搜索

- 现状：用户需要手动浏览公共模型列表。
- 提议后的行为：关键词在标题或标签中做不区分大小写的包含匹配，首尾空格被忽略。
- 验收：给定“猫咪桌面摆件”“猫咪钥匙扣”和标签含“猫咪”的公开模型，搜索 `  CAT  ` 与对应大小写的英文关键词返回相同匹配集合；关键词不在标题或标签中的模型不返回。

### 例子 2：一级分类筛选

- 现状：用户无法按项目统一分类缩小结果。
- 提议后的行为：默认分类为全部，用户每次选择一个一级分类。
- 验收：选择“钥匙扣”后只返回该分类的公开模型；切回“全部”后恢复当前关键词下的全部分类结果。

### 例子 3：关键词和分类组合

- 现状：单独条件不能快速定位目标模型。
- 提议后的行为：两个条件同时生效，结果必须同时满足关键词和分类。
- 验收：在“猫咪”关键词下选择“钥匙扣”，给定示例数据只返回猫咪钥匙扣，不返回猫咪摆件或小龙钥匙扣。

### 例子 4：分页和状态安全

- 现状：加载更多可能混入不符合条件、重复或非公开模型。
- 提议后的行为：切换条件回到第一页，后续分页只追加当前条件下的公开结果。
- 验收：连续加载更多不出现重复；审核中、审核未通过、私有和已下架模型均不出现在任何分页结果中；到达末尾显示没有更多结果。

### 例子 5：无结果、失败与清除条件

- 现状：用户无法区分没有匹配项和请求失败。
- 提议后的行为：无结果显示更换关键词或清除分类的提示；加载失败显示错误和重试；清除全部条件恢复默认公开列表。
- 验收：分别模拟空结果和网络失败，页面显示两种不同状态；点击重试重新加载；点击清除全部条件后从第一页显示公开模型列表。

### 例子 6：非法情况

- 现状：特殊关键词或伪造分类可能被用于绕过公开状态过滤。
- 提议后的行为：搜索服务先应用公开状态限制，再应用关键词和分类条件；不接受未定义的分类值。
- 验收：提交包含特殊字符、超长文本或未定义分类的条件时，不返回私有或已下架模型；未定义分类被拒绝或降级为明确错误，不被当作“全部”。
